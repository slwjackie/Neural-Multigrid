# v6.7 적응형 솔버의 계산 및 학습 범위

v6.7 초기 실험에서 풀이는 고전 multigrid로 시작한다. Hybrid 단계에서는 학습한 보간 또는 smoothing sweep이 기존 계산을 대체한다. 잔차 검사에 실패하면 마지막으로 승인된 해에서 고전 방식으로 복귀한다. 이 문서의 설정은 당시의 standalone solver에 적용된다. 이후 실험별 설정은 [문서 목록](README.md)에서 확인할 수 있다.

| 구성 | 수치 처리 |
| --- | --- |
| 계층 구성 | 고전 계층은 처음에 구성한다. Hybrid 계층은 처음 사용하는 시점에 구성하며 같은 행렬의 여러 RHS에서 재사용한다. 첫 사용의 준비 비용도 측정에 포함한다. |
| 정밀도와 커널 | 신경망은 FP32 계수를 생성하고 수치 풀이는 FP64를 사용한다. C++ stencil과 SciPy 희소 연산을 호출하며 V-cycle 재귀와 일부 line relaxation 제어는 Python에서 실행한다. |
| 적응과 복귀 | Controller는 오프라인 측정한 비용을 사용해 실행 방식을 선택한다. 고전 방식으로 복귀한 뒤에는 해당 선형계가 끝날 때까지 이를 유지한다. |
| 학습·측정 | 초기 연구 설정은 train 224개, tune 28개, audit 35개다. 각 레벨에 학습을 적용할지 여부는 같은 잔차 허용오차까지의 시간으로 비교한다. |

## 학습에서 미분하는 연산

- Smoother 계수, 보간 가중치, Galerkin 곱, coarse solve를 통해 1차 기울기를 계산한다.
- 고전 support, top-k, drop 선택은 한 번의 역전파 동안 고정하고 다음 forward에서 실제 행렬로 다시 계산한다.
- Online mode와 실행 시간은 오프라인 측정값으로 학습한다. 고정된 동작 비용은 가중치에 대한 기울기를 제공하지 않을 수 있다.
- Gate에는 straight-through 추정량을 쓴다. Forward에서는 이산 gate를 적용하고 backward에서는 연속 gate의 곱을 미분한다.
